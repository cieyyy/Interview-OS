# Interview OS Job Sync

扩展提供两种捕获模式：

- 手动捕获：仅在用户点击同步按钮时读取岗位详情或批量补全列表岗位。
- 批量补全会自动滚动当前列表并累计懒加载岗位，单次最多处理 100 个详情链接。
- BOSS 个人中心的分页岗位列表会在后台从当前页继续遍历后续分页，直到末页、没有新岗位或达到 100 条上限。
- 同步失败时会显示岗位名称、公司、失败原因和详情链接，并可一键复制失败清单。
- 批量同步的进度和结果保存在扩展本地存储中；弹窗关闭后任务继续，再次打开可恢复进度、最终结果和失败清单。
- 自动捕获：用户浏览岗位详情页时自动识别并去重同步，不自动投递、不发送消息。

Chrome MV3 配套扩展。它只读取用户已经打开并登录的招聘页面中的可见岗位，通过本机 `127.0.0.1:19426` Bridge 同步到 Interview OS。

支持站点：BOSS 直聘、猎聘、智联招聘、前程无忧、拉勾。覆盖标准搜索列表、可识别的收藏/个人中心列表和岗位详情页；列表岗位会在后台打开详情页补全后再写入职位池。招聘网站页面结构变化后，对应选择器可能需要更新。

## 安装

1. 启动 Interview OS，进入“岗位同步”。
2. Chrome 打开 `chrome://extensions/`，启用开发者模式。
3. 选择“加载已解压的扩展程序”，加载本目录。
4. 在扩展弹窗中填写 Interview OS 显示的同步令牌。
5. 打开招聘网站搜索页，点击“同步当前页面”。页面内容变化时扩展也会自动增量同步。

扩展不会读取密码、导出 Cookie、发送沟通消息或执行投递。所有招聘网站登录和验证码均由用户本人完成。
