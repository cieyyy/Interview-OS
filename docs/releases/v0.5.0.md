# Interview OS v0.5.0

## 发布主题

从面试知识库升级为本地优先的一体化求职工作台，并增加 Obsidian 知识资产单向导出。

## 主要更新

- 求职 Agent：解析城市、岗位、薪资、排除项、远程偏好和硬性条件，形成可重复运行的求职计划。
- 岗位工作台：统一接收浏览器扩展和预留连接器的数据，完成标准化、去重、筛选、对比、详情和状态管理。
- 岗位智能：提供七维匹配、可信度、数据质量、风险提示、偏见提示和生命周期状态。
- 公司关注：管理目标公司、招聘官网、优先级、招聘类型和招聘时间线。
- 求职管道与日程：跟踪收藏、准备、投递、沟通、面试、Offer、截止时间和下一步动作。
- 简历工坊：基于目标 JD、项目和技能证据建立定向简历版本。
- 能力图谱：展示已验证能力、相关经验、岗位缺口、匹配分项和补强路线。
- 数据中心：展示采集到分发的流水线、字段完整度、来源健康度和结构化报告。
- Chrome MV3 扩展：读取用户已打开招聘页面中的可见岗位，通过本机 Bridge 同步到软件。
- Obsidian Phase 1：连接或创建 Vault，预览并单向导出标准 Markdown、YAML frontmatter、WikiLinks 和稳定 ID。
- UI 规范：统一全模块字号、字重、字体家族和设计系统，并加入自动化防回退检查。

## 面试训练

- 英文模式的问题、推荐回答、教练建议和动态追问保持全英文。
- 继续支持标准训练与 2/4/6/8 轮压力面试。
- 推荐回答仍受职业档案和项目证据约束，缺失事实不会被自动编造。

## 安全边界

- 浏览器扩展不读取密码、不导出 Cookie、不绕过验证码，也不执行沟通或投递。
- 本机岗位 Bridge 仅监听 `127.0.0.1` 并使用工作区令牌鉴权。
- Obsidian 集成不读取或修改 `.obsidian`；外部修改会阻止覆盖并记录冲突。
- 自动沟通、批量投递和外部推送保持关闭。

## 验证结果

- 15 个测试文件、55 个单元与集成测试通过。
- Vue 和 TypeScript 类型检查通过。
- Electron 主进程和 Renderer 生产构建通过。
- Electron 主流程及 15 个模块字体一致性 E2E 通过。
- 打包应用冒烟测试等待 v0.5.0 Windows 产物生成后执行。

## 已知限制

- v0.5.0 Windows 安装版和便携版尚未生成。
- 招聘平台 MCP、公司官网监控和外部推送尚未完成真实授权与频率测试。
- Obsidian 当前为单向导出，不支持从 Vault 导入、文件监听或双向同步。
- `obsidian://` URI 需要在安装 Obsidian 的 Windows 机器上人工验证。
