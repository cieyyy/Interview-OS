# Interview OS v0.8.3 Windows Release Notes

Release date: 2026-08-04

## Summary

v0.8.3 is a focused desktop interaction update. It prevents long result lists from stretching the Job Agent and Capability Growth pages and keeps destructive confirmation next to its trigger.

## Changes

- The delete-plan confirmation is now a small anchored popover beside the selected delete button.
- Job Agent recommendations use a fixed three-card page with previous/next controls instead of an unbounded vertical list.
- The global capability supply-and-demand map displays up to six items per category on each page.
- The AI Career Coach header no longer displays the Job Agent shortcut; Training Reports remains available.

## Verification

- 19 test files and 93 unit/integration tests passed.
- Vue and TypeScript type checking passed.
- Six Electron end-to-end workflows passed.
- Visual screenshots verified the anchored delete popover and fixed capability-map pagination.

## Known limitations

- Windows packages remain unsigned and use the Electron default application icon.
- v0.8.3 contains Windows assets. macOS users should continue using v0.8.1 until a matching macOS build is published.
