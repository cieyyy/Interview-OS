# Interview OS v0.8.4 Windows Release Notes

Release date: 2026-08-04

## Summary

v0.8.4 completes the desktop dark theme and adds a safe Sub2API configuration template for the optional AI Provider.

## Changes

- Replaced remaining light and translucent page surfaces with a consistent near-black desktop theme.
- Covered settings, company tracking, empty states, forms, capability views, resume views, Job Agent views, and shared panels.
- Added a Sub2API template that selects the OpenAI-compatible provider, enables it, and fills an editable `/v1` endpoint example and model name.
- Preserved the existing API key field when the template is applied; no address or secret from screenshots is embedded.
- Added a production warning to use HTTPS for Sub2API endpoints.

## Verification

- 19 test files and 93 unit/integration tests passed.
- Vue and TypeScript type checking passed.
- Electron end-to-end tests verified dark surface colors and the Sub2API template fields.
- Visual screenshots verified the Settings and Company Tracking pages in dark mode.

## Known limitations

- Windows packages remain unsigned and use the Electron default application icon.
- v0.8.4 contains Windows assets. macOS users should continue using v0.8.1 until a matching macOS build is published.
