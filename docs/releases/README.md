# Release notes

- [v0.1.0](./v0.1.0.md) — 首个可运行的本地优先 MVP；

- [v0.4.0](./v0.4.0.md) — 基于 JD 的动态压力面试、证据诊断、简历校准与闭环总结。
- [v0.5.0](./v0.5.0.md) — 一体化求职工作台、岗位智能、求职 Agent、Obsidian 单向导出和统一 UI 规范。
- [v0.6.0](./v0.6.0.md) — 个人职业 AI 操作系统、统一职业教练、内置知识空间、Design System 和无损迁移。
- [v0.7.0](./v0.7.0.md) — 浏览器岗位同步升级为列表识别、后台详情补全、JD 清洗和桌面自适应岗位中心。
- [v0.8.0](./v0.8.0.md) — 多招聘网站适配、可靠批量同步、岗位动态分析、批量回收站和第八版桌面体验升级。
- [v0.8.1](./v0.8.1.md) — 第八版 macOS 兼容补丁，提供 Intel 与 Apple Silicon 的 DMG/ZIP 构建。
- [v0.8.2](./v0.8.2.md) — Windows 工作流精简、地图距离校准、动态简历技能和黑白界面偏好。
- [v0.8.3](./v0.8.3.md) — 求职计划锚定删除确认、推荐岗位卡片翻页、能力供需图翻页和教练页动作精简。
- [v0.8.4](./v0.8.4.md) — 补全全局近黑主题，并提供可一键套用的 Sub2API Provider 模板。
- [v0.8.5](./v0.8.5.md) — 修复 Sub2API 根地址调用、深色残留浅色块和项目经历窗口自适应。
