# Interview OS v0.2.0

本版本在 v0.1.0 的本地知识库和面试训练闭环上，增加图片/文件识别预填功能，并保持“不自动保存、不静默上传”的安全边界。

## 新增功能

- JD 中心上传图片或文件，预填岗位名称、公司和 JD 原文；
- 职业档案上传简历图片或文件，预填基础档案；
- 面试知识库上传图片或文件，生成可编辑知识草稿；
- 本地解析 TXT、Markdown、JSON、CSV、LOG、DOCX 和文本型 PDF；
- PNG、JPG、JPEG、WEBP 通过用户配置的视觉 AI Provider 识别；
- OpenAI 兼容接口支持 Chat Completions，并在端点不受支持时自动回退到 Responses API；
- 兼容常见 Sub2API 中转配置；
- 移除 Electron 原生菜单栏。

## 安全边界

- 只读取用户在原生文件选择器中主动选择的单个文件；
- 单文件最大 12 MB；
- 文本文档在本地解析，图片只有在用户主动选择后才发送给 AI Provider；
- 识别结果只预填表单，必须由用户检查并手动保存；
- Renderer 不获得任意文件系统读取权限；
- API Key 不进入源码、普通 JSON、Markdown 导出或日志。

## 已知限制

- 扫描版 PDF 需要先转换成 PNG/JPG 后识别；
- 图片识别要求模型具备视觉理解能力；
- DOCX 复杂排版和内嵌图片不会完整还原；
- 发布文件尚未使用商业代码签名证书。
