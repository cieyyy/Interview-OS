# Interview OS v0.8.0 Release Notes

Release date: 2026-07-23

## Summary

v0.8.0 is the eighth Interview OS release. It turns the browser job connector and Job Center into a more reliable end-to-end workflow: collect visible jobs from supported recruitment sites, enrich each job from its detail page, report failures clearly, analyze each job independently, and manage active or deleted jobs in batches.

## Added

- Manual and automatic extension capture modes.
- Persistent batch progress, failure details and copyable failed-job lists.
- Recruitment adapters for BOSS, Zhaopin, 51job, Liepin, Lagou and related supported sources.
- Custom address input and heuristic nearest-job ordering without fabricated distance values.
- Job Center batch management, recycle-bin batch restore and batch permanent deletion.
- CSV, JSON and structured job report export.

## Changed

- Detail extraction now retries dynamic pages and uses safer company/title fallbacks.
- Job details expand directly below the selected row.
- Job analysis, capability growth and dashboard targets use the selected job's own data instead of shared placeholder results.
- Sidebar navigation, parent highlighting, knowledge pagination, typography, spacing and enlarged-window responsiveness are aligned.
- Greeting drafts focus on relevant experience and interest without claiming that a resume was custom-made for the employer.

## Fixed

- BOSS job titles containing recruitment-related words are no longer rejected solely by title heuristics.
- Batch delete, restore and permanent delete are persisted through transactional workspace APIs.
- Knowledge generated from one job is no longer reused as evidence for unrelated job analyses.
- White-screen recovery, clipboard interactions, nested scrolling and text overflow are hardened.

## Known limitations

- The extension uses the user's current browser session. It never reads passwords, exports cookies, bypasses captcha, sends messages or applies to jobs.
- Login and human verification remain user-controlled. Some sites expose complete details only after login.
- Recruitment-site DOM structures can change and may require adapter maintenance.
- On this development machine, Electron source E2E currently crashes during the first page load; the same failure is reproducible with the pre-existing baseline E2E. Unit tests, type checking and production build remain verified.
- The packaged smoke test is affected by the same desktop-window availability issue and is not reported as passed.
