# Interview OS v0.3.0

## 主要更新

- 上传完整简历时同时识别基础档案与项目经历；项目按名称去重并自动保存；
- 兼容旧版 DOC、RTF/MHTML 伪扩展名、Word 表格、双栏 PDF、粘连标题和中英文项目日期；
- 项目名称无法从源文件读取时保留可编辑的“待命名项目”，不根据描述猜测；
- 项目经历新增完整编辑、修改和保存流程；
- 面试训练支持中文和 English、麦克风语音识别与题目朗读；
- 增加 AI 1V1 陪练、推荐回答和面试官追问；未配置 Provider 时自动使用本地教练；
- 训练历史可点击进入，查看问题、原回答、最终回答、评分与建议；
- 设置页改为一行一个卡片，AI 助手页仅保留进入训练入口；
- 顶部数据说明改为“本地优先 · 仅主动使用 AI 时发送所选内容”。

## 数据与隐私说明

- 职业档案、项目、JD、知识和训练记录默认只写入本地工作区；
- 本地 TXT、Markdown、DOC、DOCX 和文本 PDF 解析不发送到外部；
- 只有用户主动使用图片、扫描 PDF 识别或 AI 1V1 陪练时，所选内容或当前训练上下文才会发送给已配置的 Provider；
- API Key 不写入普通工作区文件、日志或 Markdown 导出。
