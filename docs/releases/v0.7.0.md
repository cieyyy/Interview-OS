# Interview OS v0.7.0 Release Notes

Release date: 2026-07-22

## Summary

v0.7.0 focuses on real browser-based job synchronization readiness. It keeps all v0.6.0 career OS capabilities and upgrades the Chrome extension from visible-page extraction to a safer two-step workflow: identify jobs from a recruitment list, open each job detail page in the background, extract the complete job detail, then write normalized results into Interview OS.

## Added

- Chrome extension batch mode: “列表岗位 + 后台详情补全”.
- Background detail queue with a default batch limit of 30 jobs.
- Detail page extraction path for title, company, location, salary, JD and source URL.
- List fallback when a detail page is blocked, incomplete or not recognized.
- Source trace metadata for distinguishing `detail-background-tab` and `list-fallback`.

## Changed

- Job Center source copy now describes both current-page sync and list-detail completion.
- Job Center layout now adapts to wider desktop windows instead of staying fixed at a narrow centered width.
- Job details use an internal scroll area for long JD text.

## Fixed

- Removed the unsafe full-page text fallback that could mix navigation, related jobs and login panels into one job description.
- Improved job description cleanup for recruitment-site noise such as login, registration, captcha, collect, apply and recommendation sections.
- Replaced a hard-coded 11px style with the shared design-system typography token.

## Known limitations

- The extension uses the user’s current browser session only. It does not read passwords, export cookies, bypass captcha, send messages or apply to jobs.
- Recruitment sites may change DOM structures; individual adapters may require ongoing selector maintenance.
- If a website requires login or human verification, the user must complete it manually before retrying.
