# Interview OS v0.1.0

Interview OS 的第一个可运行版本，面向 Windows 10/11 x64，核心功能完全本地可用，不依赖 Docker、WSL、Redis、PostgreSQL 或 BIOS 虚拟化。

## 核心功能

- 管理职业档案、技能和项目经历；
- 建立技术知识、故障案例和面试表达知识库；
- 粘贴 JD 后离线提取能力要求并匹配项目证据；
- 进行文字模拟面试、六维评分、重答和知识沉淀；
- 创建本地备份并导出 Markdown；
- 配置 OpenAI 兼容接口或远程 Dify Provider；
- API Key 与普通业务数据隔离存储。
