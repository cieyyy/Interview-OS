# Interview OS v0.8.2 Windows Release Notes

Release date: 2026-08-04

## Summary

v0.8.2 streamlines the desktop career workflow and publishes refreshed Windows installer and portable builds. Existing workspace data remains compatible; removed modules are hidden from navigation and their historical data is preserved.

## Product changes

- Career Agent plans can be deleted together with their associated run history.
- Career Profile now includes project experiences with one-project-per-page navigation.
- Project Assets, Job Insights, Knowledge Space, Data Center, Obsidian settings, job audit, and match breakdown have been removed from the active interface.
- Job Center can geocode the preferred address and job locations through an optional AMap Web Service key, with local fallback sorting when no key is configured.
- Resume Studio derives core skills from the selected job and project evidence and provides an edit action in the live preview.
- AI Career Coach uses one interview entry with selectable coaching modes.
- Settings include interface language preference, light/dark themes, and map configuration.

## Known limitations

- The Windows executables are not signed with a commercial code-signing certificate.
- The repository does not yet include a dedicated Windows application icon, so this build uses the Electron default icon.
- Accurate map distance requires a user-provided AMap Web Service key; the key is stored in local application preferences.
- The v0.8.2 release contains Windows assets. macOS users should continue using the v0.8.1 macOS assets until a matching macOS rebuild is published.
