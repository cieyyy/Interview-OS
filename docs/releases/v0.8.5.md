# Interview OS v0.8.5 Windows Release Notes

Release date: 2026-08-04

## Summary

v0.8.5 fixes Sub2API root URL requests, removes the remaining light surfaces in dark mode, and constrains long project modules to the application viewport.

## Changes

- OpenAI-compatible root URLs such as `http://host:port` are automatically requested through `/v1`.
- HTML gateway responses now produce an actionable Base URL and reverse-proxy error instead of an `Unexpected token '<'` JSON exception.
- Completed dark styling for Job Analysis, Job Center location controls, saved filter rules, selected tabs, and destructive actions.
- Project Experience uses a viewport-bound two-column layout; the form and recorded project content scroll independently.
- Shared product modules now enforce `min-width: 0` and viewport-safe maximum widths to prevent content from stretching their containers.

## Verification

- 19 test files and 95 unit/integration tests passed.
- Vue and TypeScript type checking passed.
- Electron end-to-end tests verified API template behavior, dark surfaces, and viewport-bound project modules.
- Visual screenshots verified Job Analysis, Job Center, saved rules, and Project Experience in dark mode.

## Known limitations

- Windows packages remain unsigned and use the Electron default application icon.
- v0.8.5 contains Windows assets. macOS users should continue using v0.8.1 until a matching macOS build is published.
