# Interview OS v0.4.0

## 主要更新

- 新增“岗位研究 → 简历证据 → 压力面试 → 回写修正 → 面试清单”的训练闭环。
- 压力面试支持 2、4、6、8 轮，一次只问一题，并依据上一轮回答动态追问。
- 自动阻止相同或高度重复的问题；回答充分后转向下一项能力验证。
- 每轮输出证据缺口、逻辑与表达漏洞、面试官可能质疑点、STAR 建议回答和简历修改建议。
- STAR 建议严格使用职业档案和项目经历中的事实，缺失内容标记为“【需要本人补充】”。
- 简历建议可同步到项目经历的“面试校准记录”，后续可继续编辑保存。
- 完成训练后生成核心优势、三个高风险漏洞、五个练习问题、简历修改建议与面试前检查清单。
- 训练报告可以回看全部轮次、诊断与最终总结。

## AI 与离线行为

- 启用 AI Provider 时，会向已配置的 OpenAI 兼容接口发送当前 JD、选定项目、职业档案、当前回答和历史训练轮次，用于严格追问和诊断。
- Provider 未启用、超时或返回格式不完整时，系统自动降级为本地规则，不影响训练闭环和数据保存。
- API Key 继续使用 Electron 安全存储，不写入普通工作区 JSON、日志或 Markdown 导出。
