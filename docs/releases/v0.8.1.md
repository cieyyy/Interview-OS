# Interview OS v0.8.1 macOS Release Notes

Release date: 2026-07-24

## Summary

v0.8.1 is the macOS compatibility update for the eighth Interview OS release. It retains the v0.8.0 product features and adds reproducible GitHub-hosted builds for Intel Macs and Apple Silicon Macs.

## Artifacts

- `Interview-OS-0.8.1-mac-x64.dmg` for Intel Macs.
- `Interview-OS-0.8.1-mac-x64.zip` for Intel Macs.
- `Interview-OS-0.8.1-mac-arm64.dmg` for Apple Silicon Macs.
- `Interview-OS-0.8.1-mac-arm64.zip` for Apple Silicon Macs.
- `SHA256SUMS-macos-v0.8.1.txt` for integrity verification.

## macOS integration

- Native application menu with About, Services, Hide and Quit.
- Native Edit menu with Undo, Redo, Cut, Copy, Paste and Select All.
- Native Window menu with Minimize, Zoom and Bring All to Front.
- Microphone usage description for user-initiated voice interview training.
- Native GPU acceleration retained on macOS.

## Local data

The packaged macOS application stores the Interview OS workspace under:

```text
~/Documents/Interview OS
```

Deleting the application does not delete this directory. Remove it separately only after exporting or backing up required data.

## Installation

1. Download the DMG matching the Mac processor.
2. Drag Interview OS into Applications.
3. Because this test release is not notarized, Control-click Interview OS in Finder and choose Open on the first launch.
4. Confirm microphone access only when voice interview training is needed.

## Verification

The GitHub macOS workflow performs:

- `npm ci`
- `npm test`
- `npm run typecheck`
- `npm run package:mac -- --x64` or `--arm64`
- Intel application bundle, `Info.plist`, executable and process-launch validation
- Best-effort Playwright UI diagnostic on the Intel build runner
- SHA-256 manifest generation

The package command explicitly uses `--publish never`; publishing is performed only by the final GitHub Actions job after both architectures pass.

## Known limitations

- The application is not signed with an Apple Developer ID and is not notarized.
- The browser job synchronization extension must be loaded into Chrome separately.
- Recruitment-site login, captcha and human verification remain user-controlled.
- GitHub-hosted macOS runners may not expose an interactive desktop window to Playwright; UI diagnostics are retained but do not block an otherwise valid bundle release.
