# Interview OS v0.6.0

v0.6.0 将产品升级为本地优先的个人职业 AI 操作系统，不删除 v0.5.0 功能或数据。

## 新增

- 12 模块产品导航和行动优先工作台。
- Design System tokens 与 12 个共享 UI 组件。
- 统一 `CoachSession` 和六种 AI 职业教练模式。
- 内置知识空间：Markdown、属性、双向链接、反向链接和关系图。
- 项目、JD、训练结果自动沉淀为结构化知识。
- schema 3 自动迁移、迁移前备份、迁移报告和 previous 恢复。

## 保留

求职 Agent、岗位洞察、职业档案、求职日程、训练报告、岗位 Bridge、Obsidian 兼容导出及全部旧数据模型继续可用。

## 验证

类型检查、60 项单元/集成测试、生产构建和两项 Electron E2E 已通过。Windows 安装版与便携版尚未生成，因此产物冒烟测试待执行。

## 已知边界

真实岗位抓取、实时官网监控、外部推送和辅助投递计划在 v0.7.0 按连接器逐项验收。外部写操作仍需用户确认。
