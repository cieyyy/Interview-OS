# 智能面试知识库助手 PRD（MVP）

> 状态：待产品评审  
> 版本：v0.1  
> 目标平台：Windows 10/11 x64 桌面应用  
> 产品形态：本地优先 + 可选联网 AI

## 1. 产品目标

### 1.1 用户目标

- 把零散职业材料整理为可复用的个人知识库；
- 针对目标岗位形成准备计划和面试问题集；
- 反复训练真实回答，并看到可解释的改进过程；
- 在不夸大经历的前提下，提高技术表达和业务表达质量。

### 1.2 业务目标

- 验证“个人知识库 + 针对性训练”是否比通用 AI 问答更有长期留存价值；
- 建立稳定的数据模型，为后续语音、云同步、远程 Dify 和第三方软件接入奠定基础；
- 形成一个可以公开演示、安装和持续迭代的个人作品。

### 1.3 非目标

- MVP 不以覆盖所有行业题库数量为目标；
- MVP 不建设招聘平台；
- MVP 不训练或微调基础大模型；
- MVP 不提供企业级账号、组织和复杂权限体系。

## 2. 核心用户故事

### US-01：建立职业档案

作为求职者，我希望记录目标岗位、技能、工作经历和项目经历，以便系统生成符合真实背景的内容。

### US-02：导入岗位 JD

作为转岗者，我希望粘贴或导入 JD，自动识别职责、硬技能、软技能和优先级，以便知道准备重点。

### US-03：整理知识卡片

作为技术人员，我希望把技术定义、实际场景、故障案例和面试表达相互关联，以便既能复习知识，也能讲清楚经验。

### US-04：进行针对性训练

作为面试准备者，我希望系统根据 JD、职业档案和历史薄弱点提问，而不是只给我通用题库。

### US-05：获得可信反馈

作为用户，我希望系统指出技术错误、证据不足、结构问题和口头表达问题，并明确区分事实与建议。

### US-06：沉淀优秀回答

作为用户，我希望把重答后的优秀内容保存为多个时长版本，并链接到项目、知识点和目标岗位。

### US-07：掌控个人数据

作为重视隐私的用户，我希望本地使用不强制注册，并能随时导出、备份或删除全部数据。

## 3. 功能范围

## 3.1 工作台

### FR-DASH-01 今日概览

展示：

- 当前目标岗位；
- 待复习知识卡片；
- 最近训练记录；
- 本周训练次数和平均分趋势；
- 建议进行的下一项任务。

### FR-DASH-02 快速入口

支持一键：

- 新建知识；
- 新建项目经历；
- 导入 JD；
- 开始模拟面试；
- 继续上一次训练。

## 3.2 职业档案

### FR-PROFILE-01 基础档案

字段至少包括：

- 姓名或昵称；
- 当前岗位、工作年限、学历；
- 目标岗位和优先级；
- 技能清单及熟练度；
- 求职城市、工作方式等可选条件。

### FR-PROFILE-02 工作经历

每段经历支持：公司/行业、时间、岗位、职责、成果、技术栈和证据附件。

### FR-PROFILE-03 项目经历

每个项目支持：

- 背景与目标；
- 系统架构；
- 用户本人职责；
- 采取的方案；
- 难点与故障；
- 可量化或可验证结果；
- 30 秒、90 秒、深入追问版本；
- 关联知识卡片和目标岗位。

### FR-PROFILE-04 真实性边界

AI 生成内容时，必须将信息分为：

- 已由用户材料证明；
- 根据上下文合理归纳；
- 尚缺信息，需要用户确认。

未经确认的内容不得保存为用户事实。

## 3.3 知识库

### FR-KB-01 内容类型

MVP 支持：

- 技术知识；
- 项目经历；
- 故障案例；
- 面试问题；
- 面试回答；
- JD；
- 普通笔记。

### FR-KB-02 编辑能力

- Markdown 编辑与预览；
- 标题、标签、状态、来源、复习日期等属性；
- 双向关联；
- 附件引用；
- 自动保存和版本快照。

### FR-KB-03 搜索与筛选

支持全文搜索，并按类型、标签、岗位、掌握状态、更新时间筛选。

### FR-KB-04 导入导出

MVP 支持：

- Markdown 文件夹导入；
- 纯文本粘贴；
- 单条或批量 Markdown/JSON 导出；
- 全量备份与恢复。

### FR-KB-05 Obsidian 兼容

知识内容使用通用 Markdown 和相对链接，保证用户可用 Obsidian 打开核心内容。产品专有状态保存为可迁移元数据，不破坏原文。

## 3.4 岗位 JD 分析

### FR-JD-01 JD 导入

支持粘贴文本和导入文本类文件。网页抓取不属于 MVP。

### FR-JD-02 结构化分析

输出：

- 岗位名称与级别；
- 核心职责；
- 必须技能；
- 加分技能；
- 业务领域；
- 软技能；
- 可能的面试环节；
- 关键词及出现频次。

### FR-JD-03 匹配分析

对每项要求标识：

- 已有证据；
- 有相关经验但表达不足；
- 缺少证据；
- 明显能力缺口。

系统必须提供匹配依据，禁止只输出一个不透明的百分比。

### FR-JD-04 准备清单

根据差距生成：立即准备、短期补强、面试前复习和暂不投入四类任务。

## 3.5 面试训练

### FR-TRAIN-01 训练设置

用户可选择：

- 目标岗位/JD；
- 面试类型：项目、技术、行为、HR、压力追问；
- 难度；
- 题目数量或训练时长；
- 文字回答；语音输入在后续版本实现。

### FR-TRAIN-02 提问策略

题目来源优先级：

1. 目标 JD；
2. 用户项目与技能；
3. 历史薄弱项；
4. 通用岗位题库。

每个问题记录生成依据。

### FR-TRAIN-03 先答后评

训练模式下，系统不得在用户首次回答前直接展示完整参考答案。用户可以主动选择“给我一个提示”。

### FR-TRAIN-04 评分维度

每次回答按以下维度分别评分并给出证据：

- 技术或内容准确性；
- 结构完整性；
- 个人贡献清晰度；
- 岗位匹配度；
- 语言自然度与冗余；
- 真实性风险。

### FR-TRAIN-05 引导式重答

系统先提出 1 至 3 个缺失信息问题，再让用户重答。用户也可直接查看优化示例，但示例必须标识新增或推断的内容。

### FR-TRAIN-06 训练结果

保存：问题、首次回答、评分、反馈、提示、重答、最终版本、使用的上下文和时间。

### FR-TRAIN-07 回写知识库

用户确认后，可把最终回答保存为面试回答卡片，并关联项目、技能、JD 和问题。

## 3.6 AI 助手

### FR-AI-01 模型提供商

MVP 先支持一个 OpenAI 兼容接口，架构上通过 Provider 适配器预留其他模型。

### FR-AI-02 可控上下文

调用前展示或允许用户查看将发送的材料范围。用户可排除某些笔记、附件或敏感字段。

### FR-AI-03 流式输出与取消

支持流式响应、取消、超时提示和重试；失败不得破坏本地原始数据。

### FR-AI-04 事实保护

生成器必须遵循：

- 缺少事实时提问；
- 不把建议当作经历；
- 输出中标记依据；
- 保存前由用户确认。

### FR-AI-05 Dify 预留

通过连接器接口预留远程 Dify API。MVP 不要求本机运行 Dify。

## 3.7 设置、安全与备份

### FR-SET-01 本地工作区

用户可选择数据目录；默认建议放在非系统盘。软件显示当前路径、大小和最近备份时间。

### FR-SET-02 凭据安全

API Key 和 Token 使用 Windows Credential Manager 或等效系统安全存储，不写入普通配置文件、日志或导出包。

### FR-SET-03 日志

日志按级别和日期滚动保存，默认脱敏 API Key、Authorization、Cookie、简历联系方式等字段。

### FR-SET-04 备份恢复

支持手动全量备份、恢复前预检和失败回滚。备份不默认包含明文凭据。

### FR-SET-05 数据删除

提供删除单条、删除工作区和清除缓存能力，危险操作必须二次确认。

## 3.8 连接器

### FR-CONN-01 统一接口

连接器至少定义：身份认证、连接测试、数据读取、数据写入、权限说明、错误映射和限流处理。

### FR-CONN-02 默认最小权限

连接器默认只读；任何向外部系统写入、发送或发布内容的操作均需要用户明确确认。

### FR-CONN-03 未来接入

预留但不在 MVP 实现：

- 其他知识库软件；
- 云盘；
- 招聘平台合规接口；
- 日历和提醒；
- 企业内部系统。

## 4. 关键业务流程

### 4.1 首次使用

```text
启动应用
→ 选择本地数据目录
→ 创建本地档案（无需注册）
→ 选择目标岗位
→ 导入简历/手工填写经历
→ 可选配置 AI
→ 导入第一份 JD
→ 生成准备清单
→ 开始首次训练
```

### 4.2 单题训练

```text
选择 JD 和训练类型
→ 系统基于证据生成问题
→ 用户首次回答
→ 系统评分并指出缺口
→ 系统提出澄清问题
→ 用户补充并重答
→ 对比两次回答
→ 用户确认最终版本
→ 回写知识库
```

### 4.3 AI 不可用

```text
AI 请求失败
→ 保留用户已输入内容
→ 显示可理解的错误原因
→ 提供重试/切换模型/离线保存
→ 用户仍可编辑、搜索和导出知识
```

## 5. 页面清单

| 页面 | 核心任务 |
|---|---|
| 首次引导 | 建立工作区、档案和目标 |
| 工作台 | 查看进度与继续任务 |
| 知识库 | 浏览、搜索、编辑和关联内容 |
| 职业档案 | 管理经历、技能和项目 |
| JD 中心 | 导入、分析和对比岗位 |
| 面试训练 | 完成提问、回答、反馈和重答 |
| 训练报告 | 查看分项评分、进步和薄弱项 |
| AI 助手 | 基于选定上下文进行辅助工作 |
| 连接器 | 配置模型与外部软件 |
| 设置与备份 | 管理数据、安全、日志和版本 |

## 6. MVP 发布门槛

只有同时满足以下条件才能发布：

- 核心数据在异常退出后可恢复；
- 无 API Key 明文日志；
- 知识库、项目、JD 和训练记录能够备份恢复；
- 断网时本地核心功能可用；
- AI 超时不会造成界面冻结或数据丢失；
- Windows 安装、卸载和升级不删除用户数据；
- 完成关键流程的自动化测试与人工验收。
