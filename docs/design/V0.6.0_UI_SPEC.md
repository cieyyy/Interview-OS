# Interview OS v0.6.0 UI 规范

## 视觉方向

延续浅蓝 Spatial UI：清晰层级、低透明度浮层、轻阴影和蓝色主操作。信息密度适配 1000px 以上 Windows 桌面窗口。

## 字体与字号

- UI：Inter, Microsoft YaHei UI, PingFang SC, Microsoft YaHei, Segoe UI。
- 代码：JetBrains Mono, Cascadia Code, Consolas。
- 页面 24px / 模块 18px / 卡片 16px / 正文 14px / 辅助 12px。
- 正文行高 1.6；标题行高 1.3；正文常规 400，标签 600，标题 700。

## 间距与几何

- 间距：4/8/12/16/20/24/32/40/48px。
- 页面左右：24px；卡片内边距：20px；模块间距：24px。
- 常规控件最小高度：44px。
- 圆角：6/8/12px；卡片阴影只用语义 token。

## 组件

`src/renderer/components/ui` 提供 Button、Card、Input、Select、Modal、Table、Tag、Badge、Empty、Loading、PageHeader、MarkdownEditor。旧 `.button/.panel/.input` 通过语义变量兼容，页面不得新增随机字号。

## 交互与可访问性

- 所有按钮和链接可键盘访问，并有 3px 可见焦点环。
- 路由切换后焦点移动到主内容区。
- 异步操作显示 loading/disabled/notice/error 状态。
- 图标统一使用 Lucide，不使用 Emoji 作为结构图标。
- 状态不能只靠颜色表达，同时显示文字或图标。
- 动画 150-200ms；`prefers-reduced-motion` 下禁用非必要动画。
- 主层级 z-index：toast 50、loading 60、skip link 70、modal 80。

## 验证

- 静态测试禁止 renderer 中硬编码 px 字号。
- E2E 遍历 12 个主模块，任何可见文本不得低于 12px。
- `npm run capture:ui` 验证 12 个主模块的统一字号、24px 页面边距、24px 标题间距和横向溢出，并生成版本截图。
- 生产构建和 Electron 主流程必须通过后才可打包。
