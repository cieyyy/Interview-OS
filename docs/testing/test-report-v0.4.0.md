## 4. 视频需求验收覆盖

1. 训练入口展示“岗位研究、简历证据、压力面试、回写修正、面试清单”闭环；
2. 压力训练支持 2、4、6、8 轮上限，并一次只问一个问题；
3. 第一轮回答后生成新的动态追问，自动测试问题不与上一题重复；
4. 每轮展示证据缺口、逻辑与表达漏洞、面试官质疑点和 STAR 建议回答；
5. 数字缺少来源、个人贡献不清、结果缺少验证等情况会被明确指出；
6. 未知事实保留“【需要本人补充】”，不自动编造数据或经历；
7. 简历修改建议可同步到对应项目经历，并在职业档案中持久化显示；
8. 达到轮次上限后生成核心优势、三个高风险漏洞、五个练习问题、简历建议和检查清单；
9. 训练报告可点击回看每轮回答、评分、诊断、追问与最终总结；
10. 应用重启后，训练沉淀的知识、JD、项目校准和训练记录保持存在。

## 6. 安全验证

- Electron 保持 `contextIsolation: true`、`nodeIntegration: false`、`sandbox: true`；
- Provider 未启用时不发生远程 AI 调用，失败时自动降级为本地诊断；
- API Key 不写入工作区 JSON、导出文件、测试夹具或应用日志；
- 压力面试仅在用户主动训练时发送选定 JD、项目、档案、问题与回答；
- 构建和测试未修改 Docker、WSL、虚拟化、系统盘配置或用户其他软件。

## 8. 已知限制

- 本地规则诊断适合识别常见证据和表达问题，行业专有事实仍需本人核对；
- 在线动态追问质量取决于模型、Sub2API 等中转站兼容性和网络状况；
- Web Speech Recognition 依赖 Chromium、Windows 语音组件、麦克风权限和网络；
- 当前安装包未使用商业代码签名证书，Windows 可能显示未知发布者；
- 当前仍使用 Electron 默认图标。
