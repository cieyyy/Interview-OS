## 4. v0.3 验收覆盖

1. 完整简历识别基础档案和两段项目经历；
2. 项目经历按名称去重后自动保存；
3. 打开已记录项目，修改结果并保存；
4. English 模式生成英文项目题目；
5. 麦克风入口与题目朗读入口显示；
6. Provider 未启用时，本地教练生成推荐回答和追问；
7. 提交答案后生成六维评分并保存最终回答；
8. 训练历史可点击，详情中显示当时的原回答；
9. AI 助手页面仅保留进入训练入口；
10. 关闭并重启后，本地项目、JD、知识和训练数据保持存在。
11. 测试运维 PDF 可识别基础档案及 3 段项目经历；
12. 旧版 Word 表格、标题粘连、项目名缺失和英文月份日期范围均有匿名化回归用例。

## 5. 安全验证

- Electron 保持 `contextIsolation: true`、`nodeIntegration: false`、`sandbox: true`；
- Renderer 只能使用预定义 IPC，不能传入任意文件路径读取；
- 麦克风权限只允许当前应用窗口请求音频，摄像头请求拒绝；
- Provider 未配置时不发生远程 AI 调用；
- 图片识别与 AI 陪练均需用户主动操作；
- API Key 不写入工作区 JSON、导出文件或应用日志。

## 7. 已知限制

- Web Speech Recognition 依赖 Chromium、Windows 语音组件、麦克风权限和网络；不可用时可继续文字作答；
- 纯图片、艺术字、复杂浮动文本框或源文件本身缺失项目名时需要人工核对；
- 在线 AI 质量取决于用户配置的模型、中转站兼容性和网络；接口失败时自动使用本地教练；
- 候选包未使用商业代码签名证书，Windows 可能显示未知发布者；
- 当前仍使用 Electron 默认图标。
