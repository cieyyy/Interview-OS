## E2E 覆盖

简历导入、项目编辑、知识导入、JD 分析、两轮英语压力训练、推荐回答、回答诊断、项目校准、训练报告、兼容 Vault 导出、断开兼容集成、重启后持久化。

子功能交互覆盖：6 种 AI 职业教练模式、求职 Agent、训练报告、职业档案、项目经历、定向简历、岗位中心 4 个标签页、岗位洞察、JD 导入、知识编辑与图谱、项目资产编辑、求职机会与日程、公司新增、数据中心 3 个标签页。

本轮定向 Electron E2E 结果：2 项通过，覆盖全部子功能视觉巡检与功能语义完整性。packaged 启动测试仍需在正式 Windows 安装包生成后执行。
